- **AI에게 준 프롬프트**
  - 11주차 실습에서 사용한 CLAUDE.md 파일을 참고해 우리 프로젝트용 CLAUDE.md 파일을 작성해줘

  - 11주차 실습에만 필요한 규칙(시간대 규칙, 예시 데이터 사용 규칙 등)을 제외함

### 3. ECOS 기준금리 수집 (src/collect_ecos.py)

- **맡긴 작업**: ECOS Open API로 기준금리(722Y001) 월별 데이터를 받아 `data/raw/ecos_base_rate.csv`로 저장하는 코드
- **AI에게 준 프롬프트**
  - ECOS Open API 받아왔어. 기준금리 월별 데이터 받아서 저장하는 코드 작성해줘
- **수정 과정**
  - 한 번에 받은 코드는 이해하기 어려워서 개념 → 코드 → 한 줄씩 의미 → 실행 확인 순서로 나눠 다시 요청함
  - 패키지 버전이 팀원마다 달라지지 않도록 가상환경(.venv)과 requirements.txt를 사용하고, 팀원 공유 메시지에 가상환경을 쓰는 이유를 추가함
  - 실행 결과 141건(201501~202609)과 금리 값(202409 3.5, 202410 3.25, 202509 2.5)을 ECOS 사이트 값과 대조함

### 4. KOSIS 소매판매액지수 수집 (src/collect_kosis.py)

- **맡긴 작업**: KOSIS Open API로 소매판매액지수(DT_1K41012)를 받아 `data/raw/kosis_retail_index.csv`로 저장하는 코드
- **AI에게 준 프롬프트**
  - KOSIS도 ECOS와 같은 구조로 만들어줘
  - (AI가 제시한 계획을 확인한 뒤) 이대로 만들어
- **수정 과정**
  - 상품군·지수 코드를 추측하지 않고 KOSIS 메타데이터(getMeta)로 먼저 확인한 뒤 작성함 (T1 경상, T2 불변, T3 계절조정)
  - raw 파일은 행을 지우지 않는다는 규칙에 맞춰, 수집 단계에서는 전체(10,152건)를 그대로 저장하고 상품군 선별은 정리·결합 단계로 넘김
  - 인증키가 들어간 요청 URL이 출력되지 않도록 오류 시 예외 이름만 출력하게 함
  - 키가 없을 때, 키가 틀렸을 때를 직접 실행해 안내 메시지가 나오고 기존 파일이 바뀌지 않는 것을 확인함
  - 2026년 9월 데이터가 공표되어 있는 것을 확인함 (교수님 피드백 2번)
