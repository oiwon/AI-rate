# 데이터 건수 검증표

## 1. 데이터 개요

- ECOS: 한국은행 기준금리 (2015.01~2026.09, 월별)
- KOSIS: 상품군별 소매판매액지수 (2015.01~2026.09, 월별)
- 분석 대상: 세부 상품군 15개, 불변지수 및 계절조정지수
- 결합 기준: 연월(YYYYMM), 다대일 결합
- 수집 일자: ECOS 2026-11-24, KOSIS 2026-11-25 (실제 Open API 호출 결과 기준)
- 실행 순서: `src/collect_ecos.py` → `src/collect_kosis.py` → `src/clean_merge.py`

**행의 의미**

- ECOS: 연월별 기준금리 1건
- KOSIS: 연월 × 상품군 × 지수 종류별 판매지수 1건
- 결합 결과: 각 상품군·지수 종류·연월에 해당 월의 기준금리를 연결한 1건

## 2. 정리 단계 건수 검증

### ECOS 기준금리

| 단계 | 건수 |
|---|---:|
| ECOS 원본 | 141 |
| − 중복 연월 | 0 |
| − 결측 행 | 0 |
| **= 정리 후** | **141** |

검증식: 141 − 0 − 0 = 141

### KOSIS 소매판매액지수

| 단계 | 건수 |
|---|---:|
| KOSIS 원본 | 10,152 |
| − 경상지수(T1) | 3,666 |
| − 불변지수(T2) 중 분석 대상 외 상품군 | 1,551 |
| − 계절조정지수(T3) 중 분석 대상 외 상품군 | 705 |
| − 중복 행 | 0 |
| − 결측 행 | 0 |
| **= 정리 후** | **4,230** |

검증식: 10,152 − 3,666 − 1,551 − 705 − 0 − 0 = 4,230

제외 내역은 다음과 같다. `clean_merge.py`는 세 항목을 합쳐 "선별 제외 5,922건"으로 출력하며(3,666 + 1,551 + 705 = 5,922), 세부 건수는 원본 CSV를 지수 코드·상품군 코드별로 세어 확인하였다.

- 경상지수(T1): 26개 상품군 × 141개월 = 3,666건. 물가 상승분이 섞여 있어 분석에서 제외한다.
- 불변지수(T2) 대상 외 11개 상품군 × 141개월 = 1,551건: 총지수(G0), 합계(승용차 제외, G01), 내구재(G1), 준내구재(G2), 비내구재(G3), 국내 승용차(G111), 수입 승용차(G112), 통신기기(G131), 컴퓨터(G132), 신발(G221), 가방(G222)
- 계절조정지수(T3) 대상 외 5개 상품군 × 141개월 = 705건: 총지수(G0), 합계(승용차 제외, G01), 내구재(G1), 준내구재(G2), 비내구재(G3)

## 3. 결합 단계 건수 검증

| 단계 | 건수 |
|---|---:|
| KOSIS 정리 후 전체 | 4,230 |
| 매칭 성공 | 4,230 |
| 매칭 실패 | 0 |
| **= 결합 결과** | **4,230** |

검증식: 4,230 = 4,230 + 0

## 4. 검증 방법

- 상품군 코드 15개 및 지수 코드 T2(불변지수), T3(계절조정지수)를 선별하였다.
- ECOS는 연월, KOSIS는 연월·상품군 코드·지수 코드 조합으로 중복 여부를 검사하였다.
- 기준금리와 판매지수를 숫자로 변환한 뒤 결측 여부를 확인하였다.
- 연월을 기준으로 다대일 결합하고, Pandas의 `_merge` 표시를 이용해 매칭 성공·실패 건수를 계산하였다.
- 결합 CSV에서 15개 상품군, 2개 지수, 201501~202609 기간과 상품군별 282건을 추가 확인하였다.
- 매칭 실패가 0건이므로 기록할 실패 연월은 없다. 두 데이터 모두 201501~202609의 141개월이 빠짐없이 있어, ECOS에만 있거나 KOSIS에만 있는 연월도 없다.

## 5. 피드백 반영 및 값 검산

- **2026년 9월 공표 여부**: KOSIS에 2026년 9월 소매판매액지수가 공표되어 있다(통계표 최종 시점 2026.09, 해당 월 최종 수정일 2026-10-22). 따라서 결측월 없이 141개월을 그대로 사용한다. 최근 월은 잠정치라 다시 수집하면 값이 바뀔 수 있어, KOSIS 최종 수정일(`LST_CHN_DE`)과 수집 일자(`collected_at`)를 함께 저장하였다.
- **완료 기준 검산**: 결합 결과에서 승용차(G11) 계절조정지수는 2024년 9월 108.4, 2025년 9월 114.2이다. 전년동월비는 (114.2 ÷ 108.4 − 1) × 100 = 5.35%로 요건정의서의 완료 기준 값과 일치한다. 같은 달 기준금리는 2.50%이다.

## 6. 검증 결과

ECOS 기준금리 141건과 KOSIS 선별 데이터 4,230건을 연월 기준으로 결합하였다. 결합 결과는 4,230건이며 매칭 실패는 0건으로 확인되었다.

2015년 데이터는 전년동월비 계산을 위한 보조 데이터로 보관하며, 실제 분석 기간은 2016.01~2026.09이다.
