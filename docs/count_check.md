# 데이터 건수 검증표

## 1. 데이터 개요

- ECOS: 한국은행 기준금리 (2015.01~2026.09, 월별)
- KOSIS: 상품군별 소매판매액지수 (2015.01~2026.09, 월별)
- 분석 대상: 세부 상품군 15개, 불변지수 및 계절조정지수
- 결합 기준: 연월(YYYYMM), 다대일 결합

**행의 의미**

- ECOS: 연월별 기준금리 1건
- KOSIS: 연월 × 상품군 × 지수 종류별 판매지수 1건
- 결합 결과: 각 상품군·지수 종류·연월에 해당 월의 기준금리를 연결한 1건

## 2. 정리 단계 건수 검증

| 단계 | 건수 |
|---|---:|
| KOSIS 원본 | 10,152 |
| − 분석 대상 외 상품군 및 지수 | 5,922 |
| − 중복 행 | 0 |
| − 결측 행 | 0 |
| **= 정리 후** | **4,230** |

검증식: 10,152 − 5,922 − 0 − 0 = 4,230

ECOS 원본은 141건이며, 연월 중복과 기준금리 결측이 발견되지 않았다.

## 3. 결합 단계 건수 검증

| 단계 | 건수 |
|---|---:|
| KOSIS 정리 후 전체 | 4,230 |
| 매칭 성공 | 4,230 |
| 매칭 실패 | 0 |
| **= 결합 결과** | **4,230** |

검증식: 4,230 = 4,230 + 0

## 4. 검증 방법

- 상품군 코드 15개 및 지수 코드 T2(불변지수), T3(계절조정지수)를 선별하였다.
- ECOS는 연월, KOSIS는 연월·상품군 코드·지수 코드 조합으로 중복 여부를 검사하였다.
- 기준금리와 판매지수를 숫자로 변환한 뒤 결측 여부를 확인하였다.
- 연월을 기준으로 다대일 결합하고, Pandas의 `_merge` 표시를 이용해 매칭 성공·실패 건수를 계산하였다.
- 결합 CSV에서 15개 상품군, 2개 지수, 201501~202609 기간과 상품군별 282건을 추가 확인하였다.
- 매칭 실패가 0건이므로 기록할 실패 연월은 없다.

## 5. 검증 결과

ECOS 기준금리 141건과 KOSIS 선별 데이터 4,230건을 연월 기준으로 결합하였다. 결합 결과는 4,230건이며 매칭 실패는 0건으로 확인되었다.

2015년 데이터는 전년동월비 계산을 위한 보조 데이터로 보관하며, 실제 분석 기간은 2016.01~2026.09이다.
