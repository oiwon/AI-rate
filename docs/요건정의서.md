# 요건정의서 (팀과제1, 피드백 반영본)

A조: 윤중빈(20212492), 이경원(20222570), 이상민(20232856)

## 1. 주제

금리가 움직이면 무엇이 덜 팔리는가? 기준금리 변화에 대한 상품군별 소비 민감도 대시보드

## 2. 데이터

| 구분 | 데이터 (출처) | 주요 항목 | 주기 · 기간 | 수집 방식 |
|---|---|---|---|---|
| 수집 API | 한국은행 ECOS Open API: 기준금리, 통계표 722Y001 / 항목 0101000 | TIME: 연월(YYYYMM), DATA_VALUE: 기준금리(연%) | 월별, 2015.01 ~ 2026.09 (141개월) | ECOS Open API (StatisticSearch) |
| 결합 데이터 | KOSIS 재별 및 상품군별 소매판매액지수 (2020=100), 통계표 DT_1K41012 | PRD_DE: 연월(YYYYMM), C1_NM: 상품군, ITM_NM: 지수 종류, DT: 지수값 | 월별, 2015.01 ~ 2026.09 | KOSIS 공유서비스 Open API |

### 분석 대상 상품군 (15개)

총지수 및 재별 지수(내구재, 준내구재, 비내구재)는 제외하고, 불변지수와 계절조정지수가 모두 있는 세부 상품군 15개를 분석한다.

| 구분 | 상품군 |
|---|---|
| 내구재 | 승용차, 가전제품, 통신기기 및 컴퓨터, 가구, 기타내구재 |
| 준내구재 | 의복, 신발 및 가방, 오락·취미·경기용품, 기타준내구재 |
| 비내구재 | 음식료품, 의약품, 화장품, 서적·문구, 차량연료, 기타비내구재 |

### 결합 기준

- 연월(YYYYMM)을 기준으로 다대일 결합한다. KOSIS의 (상품군 × 지수 종류 × 월) 각 행에 같은 연월의 ECOS 기준금리(월말 기준 값) 1건을 붙인다. 두 데이터의 연월 형식을 YYYYMM으로 통일한다.
- 예상 건수: ECOS 141건, KOSIS 선별 후 141개월 × 15개 상품군 × 2개 지수 = 4,230건, 예상 결합 결과 4,230건. 실제 건수와 차이가 생기면 원인을 건수 검증표에 기록한다.
- 데이터 수집 및 결합 기간은 2015.01~2026.09이며, 2015년 데이터는 전년동월비와 금리 변화폭 계산을 위한 보조 데이터로 활용한다. 실제 분석 기간은 2016.01~2026.09(129개월)이며, 금리 인상기와 인하기가 모두 포함된다.

## 3. 요건

### 목적
기준금리 변화에 상품군별 소비가 얼마나, 몇 개월 뒤에 반응하는지 보여 주어, 재고·마케팅 예산을 조정할 우선순위와 시점을 정하도록 돕는다.

### 사용자
소매·유통업체의 상품기획(MD) 및 경영기획 담당자

### 가설
- **H1.** 내구재에 속하는 상품군은 다른 상품군에 비해 금리 상승 후 판매지수 하락 폭이 상대적으로 크다.
- **H2.** 음식료품은 금리 변화에 거의 반응하지 않는다.
- **H3.** 반응은 즉시가 아니라 수개월의 시차를 두고 나타난다.

### 기능 요구사항
- [필수] 상품군(복수 선택)·분석 기간·지수 종류·최대 시차 선택
- [필수] 선택한 조건의 결과(출력 항목) 확인
- [있으면 좋음] 코로나19 시기(2020~2021) 제외 옵션
- [나중에] 환율·소비자물가 등 추가 지표, 지역·기업 단위 분석

### 입력
- 상품군: 15개 중 복수 선택, 기본값 전체
- 분석 기간: 시작·종료 연월, 범위·기본값 2016.01~2026.09
- 지수 종류: 계절조정지수/불변지수, 기본값 계절조정지수
- 최대 시차: 0~12개월, 기본값 6개월

### 처리
- 수집: ECOS·KOSIS API를 호출해 결과를 파일로 저장하고, 화면에서는 저장된 파일을 사용한다. 인증키는 .env에 두고 코드에 직접 적거나 GitHub에 올리지 않는다(.gitignore에 .env 등록).
- 정리·결합: 문자열 값을 숫자로 변환하고, 연월 기준으로 결합한 뒤 건수 검증표를 만든다.
- 분석: 상품군별로 기준금리(수준, 변화폭)와 판매지수 전년동월비의 시차별(0~N개월) 상관계수를 구하고, 금리 인상기·인하기의 평균 증감률을 비교한다.
- 제공: FastAPI 서버가 분석 결과를 제공하고, Streamlit 화면이 이를 보여 준다.

### 출력
- 판매지수 전년동월비(%) = (당월 판매지수 ÷ 전년 동월 판매지수 − 1) × 100
- 기준금리 변화폭(%p) = 당월 기준금리 − 전년 동월 기준금리
- 시차별 상관계수 = 기준금리 수준·변화폭(t월)과 판매지수 전년동월비(t+k월)의 상관계수, k=0~최대 시차(개월)
- 민감도 순위: 가장 강한 상관이 나타난 시차 k와 상관계수, 절댓값이 큰 순으로 정렬(수준, 변화폭 각각)
- 금리 인상기·인하기 평균 증감률 = 금리 인상기(변화폭>0)와 인하기(변화폭<0) 각각에 속하는 월의 판매지수 전년동월비 평균. 변화폭이 0인 월은 제외한다.
- 결과 요약 문장 (예: "승용차는 금리 인상 n개월 뒤 판매가 줄어 재고를 먼저 조정할 필요가 있습니다")

### 예외 처리
- 인증키 없음: data/sample의 샘플 데이터로 실행한다(다른 팀의 교차 실행 대응).
- API 오류·호출 한도 초과: 마지막으로 저장된 파일을 사용하고 화면에 수집 일자를 표시한다.
- 기간 불일치·결측월: 두 데이터의 공통 기간만 결합하고, 제외된 월을 건수 검증표에 기록한다.
- 값 변환 실패(빈 값 등): 해당 행을 제외하고 제외 건수를 기록한다.
- 잘못된 입력(시작>종료, 상품군 미선택): 안내 메시지를 보여 주고 결과는 표시하지 않는다.
- 범위 밖의 값을 넣거나 결과가 0건이어도 서버와 화면이 멈추지 않고 안내 메시지를 보여 준다.

### 완료 기준
- 기본값을 넣어 실행하면 출력 항목이 모두 화면에 표시된다.
- 승용차 계절조정지수의 전년동월비(%)(2025년 9월 기준): (114.2 ÷ 108.4 − 1) × 100 = 5.35%
- 기준금리 변화폭(%p)(2025년 9월 기준): 2.50 − 3.50 = −1.00%p (인하기)
- 건수 검증표의 수집·결합·제외 건수가 맞고, 숫자 변환과 상관계수 계산 테스트를 통과한다.
- 민감도 순위가 상관계수 절댓값이 큰 순서대로 정확하게 표시된다.
- 인증키 없이도 샘플 데이터로 정상 실행되며, 다른 팀이 README만 보고 설치·실행에 성공한다.
